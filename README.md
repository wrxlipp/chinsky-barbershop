# Барбершоп «CHINSKY» — лендінг

Односторінковий адаптивний сайт барбершопу у Львові.

**Демо:** https://wrxlipp.github.io/chinsky-barbershop/

## Що реалізовано
- Адаптивна верстка (від 320px до 1920px) із бургер-меню на чистому CSS
- Блок послуг, тарифні пакети з виділеною пропозицією та таблиця додаткових послуг
- Секція майстрів, блок із фоновим відео та форма онлайн-запису
- CSS-змінні, БЕМ-іменування, плавні переходи (`transition`), `transform` та `@keyframes`
- Підтримка доступності (`:focus-visible`, `prefers-reduced-motion`)

## Технології
HTML5, CSS3, Flexbox, CSS Animations, Media Queries.
